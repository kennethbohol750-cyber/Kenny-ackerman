Problem-Solving & Cybersecurity Case Studies

Documented troubleshooting logs and defensive security practices

Troubleshooting Case #1: Wi-Fi Connectivity Failure

  • Problem: A workstation loses its wireless connection after a driver update, preventing the user from accessing the network.
  • Possible Causes: The issue may come from an incompatible or damaged Wi-Fi driver, a stopped WLAN AutoConfig service, or an incorrect IP configuration.
  • Diagnostic Procedure: Check the wireless status and Device Manager, refresh the IP address with ipconfig /release and ipconfig /renew, then confirm that WLAN AutoConfig is running.
  • Solution: Roll back the wireless adapter driver, restart the workstation, and clear the DNS cache with ipconfig /flushdns before checking the connection again.
  • Lesson Learned: Confirm driver compatibility before major operating system updates, then test network access after the update to catch connection problems early.

Cybersecurity Case: SQL Injection Prevention

  • Vulnerability: A login form that inserts user input directly into a database query could be exposed to SQL injection.
  • Risk: An attacker could attempt to bypass authentication, access private records, or gain privileges that should be restricted.
  • Prevention Strategy: Use prepared statements and parameterized queries, such as PDO in PHP, so user input is handled as data rather than executable SQL.
  • Security Practice: Validate input, limit database accounts to the permissions they need, and add multi-factor authentication where appropriate.
